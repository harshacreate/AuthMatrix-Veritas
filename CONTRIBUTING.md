Project notes

Use the local sample API and the fake accounts in this project. Keep the broken API, fixed API and block-all API separate. Never add real accounts, passwords or calls to other services.

Check requests that should work and requests that should fail. Include different roles and records owned by different users. Keep the broken example separate from the fixed one. The results apply only to the sample routes you checked.

Run the checks with `python -m pytest -q` or `make test`. Start the demo with `make run`.
